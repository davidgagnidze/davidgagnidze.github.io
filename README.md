# David Gagnidze Portfolio

Static portfolio website for data science and machine learning roles.

## Files To Deploy

- `index.html`
- `david_cv.pdf`
- `public/hero-data-workspace-focused.png`
- `public/projects/*.png`

No Node, Nuxt, build command, or dev server is required.

## Local Preview

Open `index.html` directly in a browser.

## Deployment

Use static hosting such as GitHub Pages, Netlify, Vercel static output, Cloudflare Pages, or any simple web host. The publish directory is the project root.
