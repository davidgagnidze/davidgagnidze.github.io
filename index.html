Public GitHub · Forecasting Dashboard

Dayton Electricity Demand Forecasting

End-to-end time-series case study predicting Dayton electricity demand one hour and 24 hours ahead using load history, weather context, baseline comparison, and chronological evaluation.

Problem

Forecast hourly electricity demand while handling irregular timestamps, daylight-saving issues, and high-demand alert thresholds.

Approach

Timestamp-preserving merge of Kaggle load and ERA5 weather, past-only features, XGBoost tuning, and Streamlit/DuckDB analysis.

Evaluation

Chronological split, persistence baselines, leakage controls, MAE/RMSE, peak-alert confusion analysis, and SQL error analysis.

Result

XGBoost MAE: 16.69 MW at h1 vs. 62.35 MW persistence; 107.40 MW at h24 vs. 161.83 MW persistence.

Demonstrates: time-series validation, feature engineering, baseline comparison, forecasting evaluation, and dashboard communication.

Scope note: retrospective portfolio project; the dashboard reads saved holdout predictions and does not run live inference.
